# Project-Subscription-business-analysis

This project analyzes subscription platform data using Python, pandas, matplotlib, and seaborn.

## Features
- Exploratory Data Analysis (EDA)
- Revenue and KPI analysis
- Subscription plan analysis
- Loyal user and retention analysis
- Correlation and outlier analysis
- Data visualization with charts and heatmaps

## Technologies
- Python
- pandas
- matplotlib
- seaborn

## Skills Demonstrated
- Data analysis
- Subscription analytics
- KPI reporting
- Customer retention analysis
- Trend analysis
- Data visualization
